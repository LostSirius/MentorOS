## Nine-stage → Scholar modules

| AERS stage | Scholar module | Distilled action |
|------------|----------------|------------------|
| 1 Topic refine | Idea | Falsifiable RQ |
| 2 Lit review | Literature | Screen + synthesize |
| 3 Data | Experiment | Data availability card |
| 4 Identification | Experiment | Controls / causal assumptions (ML: fair comparisons) |
| 5 Estimation | Experiment | Analysis plan |
| 6 Robustness | Experiment + Review | Sensitivity checklist |
| 7 Tables/figures | Figures | Publication formatting |
| 8 Write + review | Writing + Polish + Review | Draft + polish + mock review |
| 9 De-AIGC + submit | Polish + Review | Tone + submission pack |

## Product principles stolen cleanly
1. Artifact-idempotent stages (save JSON packets).  
2. Human can interrupt any stage and resume.  
3. Robustness is first-class, not an afterthought.  
4. De-AI polish is a gate before submission readiness（Polish 模块）。

## Do not port
23k community skills / Stata-only stacks. Keep stage contracts + StatsPAI/AER “identification→robustness→R&R” culture.
