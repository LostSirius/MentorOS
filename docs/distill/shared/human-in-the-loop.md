# Shared · Human-in-the-Loop（人在回路）

> 来源：Vibe Research 六规则 + ARS “copilot not pilot” + AERS 可介入流水线。

## 六规则（产品文案可直接用）

1. **允许 AI**：检索整理、代码脚手架与调试、语言润色与结构建议。  
2. **必须人拥有**：idea、问题框架、研究设计、技术路线、实验计划、核心结论、新颖性主张。  
3. **必须核验**：代码要跑懂；散文逐句对照证据；数字追溯产物。  
4. **禁止假引用**。  
5. **禁止学术不端**：代写科学判断、隐瞒 AI 代写核心贡献、伪造数据。  
6. **遵守会场/学校披露政策**。

## 产品交互铁律

- 每一阶段产物可导出、可编辑、可再跑。  
- 关键裁决（Pivot / 投稿就绪 / 删除声称）必须有**显式确认**。  
- 禁止默认“一键自动发论文”；允许“一键跑完当前阶段草稿”。  
- AI-Scientist 式全自动仅可作为**高级可选实验模式**，默认关闭且强制 integrity。

## 阶段人工介入点（最低集合）

| 阶段 | 人必须确认 |
|------|------------|
| 文献 | RQ 定稿；是否接受综述结论 |
| Idea | 裁决与是否进入实验 |
| 实验 | 配方定稿；真实结果上传/粘贴后才写 Results |
| 写作 | 证据不足段落的删改；润色语义 diff |
| 图表 | 图要表达的 claim |
| 审稿 | 哪些意见必改 |
| 总览 | 是否标记投稿就绪 |
