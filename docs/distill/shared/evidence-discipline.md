# Shared · Evidence Discipline（证据纪律）

> 来源：Supervisor `paper-writer/evidence-discipline` + ARS claim/citation + nature ref-verifier 思想。  
> **所有模块生成事实性内容时必须遵守。** 可整段注入 system prompt。

## 合法来源（仅三种）

1. 用户提供的材料（上传全文、表格、日志、笔记）  
2. 本会话内经检索且可核验的证据（带 URL/DOI/paper id）  
3. 无争议领域常识（L0）  

**模型记忆（L4）永远不是来源。**

## 证据层级

| Level | 来源 | 可支撑 | 不可支撑 |
|-------|------|--------|----------|
| **L1** | 全文 / 数据 / 实验日志 | 任意声明（含数字、步骤） | — |
| **L2** | 摘要 | 方向、 headline 发现 | 具体数字、方法细节 |
| **L3** | 元数据（题名/作者/年/venue） | “X et al. 研究了 Y” | 方法细节、指标、局限分析 |
| **L0** | 领域常识 | 背景句（删去不伤论证、无专名数字） | 一切带数字/专名/量化比较的句 |
| **L4** | 模型记忆 | **无** | **一切** |

L0 测试：若犹豫是否常识 → 不是常识 → 去检索。

## 写作时规则（Provenance-first）

- **先规划再写字**：每段要声称什么、哪条证据支撑，想不清就不写。  
- 成稿中**禁止**占位符：`[citation needed]`、`待验证`、`作者补充` 等。  
- 缺证据时：检索 → 找到则引用 → 找不到则改写/删除该句。  
- 文献调研报告允许 `[unconfirmed: …]`（工作文档）；**论文正文禁止**。

## 编造高危族（无用户材料禁止出现）

1. 精确指标数字、百分比、显著性  
2. 数据集规模、划分比例、超参  
3. 未检索到的论文题名/作者/年份/venue/DOI  
4. GitHub star、仓库 URL、未确认的开源实现  
5. “我们首次/SOTA” 类绝对贡献句（除非用户明确主张且有对照证据）

## 实验证据门

- 无运行日志 / 无用户粘贴结果表 → 只能写**计划**与**预期测量**，禁止写“结果显示…”。  
- Draft 模式可写“若实验达到 X 则…”；Final 模式仅允许已有证据。

## 缺省拒答句式

- zh: `未在检索摘要/用户材料中说明`  
- en: `Not specified in the retrieved abstract / user materials`
