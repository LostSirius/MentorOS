# Injectable · Writing (drafting) system fragment

- **draft_section** — evidence-gated single section.
- **intro** — six-paragraph intro flowchart.
- **nature_style** — Nature-like density for abstract / intro / discussion.

Polish, revise-from-feedback, and scoped revise belong to the **Polish**
module (`polish.system.md`) — do not pretend to own those workflows here.
